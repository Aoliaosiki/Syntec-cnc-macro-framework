# 宏改动手册：同步矩阵、检查清单、备份与交付

> 改宏前先看同步矩阵，改完按清单自检，交付前确认备份与安装顺序。

- 第一部分：改动同步矩阵
- 第二部分：检查清单
- 第三部分：备份与交付目录

# 第一部分 改动同步矩阵

> 改一个宏往往不止改一个文件。下表是通用同步项；具体文件名/参数号按你的包填写。
> 客户特定的参数号、报警号、机型差异与验收口径不放在公开版，按你的私有知识库核对。

## 一、按改动点

| 改动点 | 必须同步 | 不能漏的检查 |
|---|---|---|
| 宏入口/引数 | 主宏 + 所有同功能 M/O 孪生 + 调用方程序 + 交付说明 | 引数互斥、未给值、越界、旧版回退 |
| 变量/寄存器 | 主宏 + 孪生 + PLC + 画面 + 变量台账 + 交付说明 | 地址占用、型态、单位、生命周期、写后 `WAIT()` |
| 写回逻辑 | 主宏 + 孪生 + 参数说明 + 报警 | 写坐标系/刀表/磨耗的目标是否一致 |
| 参数新增/改名 | 参数表 + 三语 XML + 宏读取点 + PLC 引用 + 画面 | 单位、上下限、默认值、旧号兼容 |
| 报警新增/改号 | 报警 XML/CSV + 三语 + 所有调用点 | 一号一义、占位替换、号段上限 |
| 画面改动 | `MST.xml`/`Backgnd.xml` + 寄存器 + 宏 + PLC | 页面入口、焦点、自动清零、权限 |
| PLC 改动 | 源工程 + 编译产物 + 宏握手 + 文档 | 编译产物不可读，必须留源工程 |
| 安装包 | 覆盖顺序 + 旧文件回退检查 | 先客制包 → 再覆盖报警/参数/宏 |
| 文档/需求表 | 变更记录 + 验证步骤 + 版本日期 | 不能只写“已修改” |

## 二、单位 / 精度 / 公英制

| 改动点 | 必须同步 | 不能漏的检查 |
|---|---|---|
| 改 `Pr17` 依赖 | 主宏 + 所有孪生 + 参数说明/交付文档 | 公制 0.01/0.001/0.0001mm；英寸 0.001/0.0001/0.00001in；`/10`、不变、`*10` 的方向 |
| 改 `Pr3241` 分支 | 主宏 + 孪生 + 参数说明 + 验证记录 | `=0` 与 `=1` 分别测；`=1 + G70` 是否二次缩放 |
| 改 `G70/G71` 切换 | 主宏 + 所有退出路径 + 交付文档 | 保存/恢复 `#1010`；同时恢复 `G90/G91`、`G94/G95`；报警退出也要覆盖 |
| 改长度/坐标换算 | 主宏 + 孪生 + `G10 L2/L10/L11` 写回点 + 文档 | 英寸长度 `/2.54`，不是 `/25.4`；参数镜像 `@108xxx` 是 0.001mm |
| 改速度/进给换算 | 主宏 + 孪生 + 攻牙/量测段 + 文档 | 英寸速度 `/25.4`；攻牙 `G70 1.0/#8`、`G71 25.4/#8` |
| 改角度换算 | 主宏 + 孪生 + 画面/参数 + 文档 | `0.001°`→`/1000.`；`PARAM(n)/1000` 是否故意取整 |
| 改计数/存储系数 | 主宏 + 孪生 + 文档 | 每单位计数与写回存储系数不是同一个量；`CASE` 必须补 `ELSE` 兜底 |
| 改固定 `/1000.` 的量 | 主宏 + 孪生 + 交付文档 | 参数镜像固定 mm；G70 下与英寸变量是否同口径 |

## 三、按文件类型

| 文件 | 编码/格式 | 注意 |
|---|---|---|
| `Macro/*` | 常见 GBK，逐文件原换行 | 禁止整目录转 CRLF；禁止整文件重写 |
| `ParamExt_*.xml` | UTF-8 + BOM | 三语同改，ID 与参数号对应 |
| `AlarmMacro_*.xml` | UTF-8 + BOM | 前缀/占位/号段 |
| `AlarmPLC_*.xml` | UTF-8 + BOM | 真报警与提示分区 |
| `*.pxt` | 文本 | `value` 不预置现场值；`min/max` 与宏校验一致 |
| `*.lad`/PLC | 编译产物 | 文本检索不可靠，改逻辑要有源工程 |
| 客制画面 XML | UTF-8 + BOM | 与宏/PLC 寄存器一一对应 |

## 四、交付顺序

1. 备份原包；
2. 先装客制画面/依赖包；
3. 再覆盖参数、报警、宏；
4. 最后 PLC/驱动/系统版本；
5. 逐项验证并记录版本。

顺序反了，安装包里的旧文件会把新改动覆盖回去。

## 五、最常见漏改

- 只改 G 码主宏，没改同功能 M/O 入口；
- 只改简中报警，繁中/英文仍是占位；
- 改了参数号，没改三语说明和画面；
- 改了宏读取的寄存器，没改 PLC 写入点；
- 改了变量地址，没查 PLC/画面/其它宏占用，也没更新变量台账；
- 只改交付包，没改安装包内嵌文件；
- 改了逻辑，没更新文件头版本/日期。
- 改了公制分支，没测 `G70` 英寸分支与 `Pr17=1/2/3` 组合；
- 把参数镜像 `@108xxx` 当当前 LIU，或把长度 `/2.54` 写成 `/25.4`；
- 主动切了 `G70/G71`，正常路径恢复了，报警/中断退出没恢复；
- 只测 `Pr3241=0`，漏了 `=1` 或 `=1 + G70` 的叠加分支。

# 第二部分 检查清单

## A. 改动前（10 项）

- [ ] 确认目录类型（全备份 / 交付包 / 单个 Macro 目录）
- [ ] 确认机型（同客户可能多机型，参数/报警/入口会分叉）
- [ ] 按内容指纹判定每个宏的功能，不以文件名为准
- [ ] 判定任务所需能力级别（L1 本地 / L2 规格校验 / L3 交付）
- [ ] 查最新规格/验收资料，确认是否已变更
- [ ] 若云端不可用：记录原因，结论标 `云端校验：未完成`
- [ ] 确认“最新版”：目录日期 + 文件时间 + 关键文件哈希互证
- [ ] 读原文件全文，尤其头部注释里的引数与参数说明
- [ ] 列出同功能孪生与三语关系
- [ ] 备份已有；用户说“有备份”时不要重复造备份目录

## B. 改动中（5 项）

- [ ] 保留编码、原换行、BOM；禁止整文件重写
- [ ] `old` 字符串唯一命中；含中文/空格时用计划文件传参
- [ ] 主宏改了，按实际 diff 同步所有同功能孪生
- [ ] 参数/报警改了，同步三语说明
- [ ] 复制整套到工作目录再改，不要只拷单文件

## C. 交付前（15 项）

- [ ] 孪生差异为 0（仅允许注释差异）
- [ ] 宏内每个报警号都有定义，且不是占位
- [ ] 无“同号异义”
- [ ] 报警号段未超出定义范围
- [ ] 参数上下限与宏校验一致；默认值不预置现场值
- [ ] 参数/报警三语齐全
- [ ] XML 可解析，编码/BOM 未变
- [ ] PLC 逻辑变更已同步源工程/编译产物
- [ ] 安装包内嵌文件不会被后续覆盖；交付顺序已写明
- [ ] 客制画面随包交付
- [ ] 首设参数清单已列出
- [ ] 验证步骤覆盖正常流程 + 边界 + 中断重跑
- [ ] 文档/需求表已同步
- [ ] 已附云端校验记录（页面/版本/结论）或标注未完成
- [ ] 已按同步矩阵核对孪生、三语、参数、报警、画面、PLC、安装包

## C2. 变量/寄存器专项（6 项）

- [ ] 引数只占 `#1~#26`，临时值用 `#27~#400`；没有把 `#33` 当“第 33 个引数”
- [ ] `@`/`R` 已写明“谁写、谁读、型态、单位、生命周期”，并确认没有被 PLC/画面/其它宏占用
- [ ] 参数的 `#` 只读镜像、`PARAM(n)`、`@`/R 镜像没有互当等价；单位已按参数定义换算
- [ ] 写 R 后、读同一 R 前已加 `WAIT()`；小数已按 32 位整数放大
- [ ] `#[...]`/`@[...]` 的指针已初始化并做范围检查；刀表索引基址与刀表型态一致
- [ ] 变量台账已与 PLC 工程、画面 XML、同功能孪生交叉查重

## C3. 单位/精度专项（6 项）

- [ ] 已确认 `#1010`（G70/G71）、`Pr17`（1/2/3）、`Pr3241`（0/1），并按对应分辨率换算
- [ ] 参数镜像 `@108xxx` 没有被当成当前 LIU；R/LIU 换算按 `Pr17` + `G70/G71` 查表
- [ ] 英寸侧长度 `/2.54`、速度 `/25.4`、μm→mm `/1000.`、角度 0.001°→° `/1000.` 没有混用
- [ ] `Pr3241=0` 与 `=1` 两支都测过（或明确标注只支持哪一支）；`=1 + G70` 的叠加分支已实测
- [ ] `G10 L1000/L10/L2/L11` 写入值按 LIU/当前单位，写后用 `#`/`@`/`PARAM()` 读回验证
- [ ] 主动切 `G70/G71` 的宏已在所有正常/异常退出前恢复，且没有漏掉 `G90/G91`、`G94/G95`

## D. 常见坑

1. **G53 段写 F 无效**：普通 F 可能被忽略；需要限速时用控制器支持的限速写法。
2. **整数除法与浮点**：`#7/2` 会截断，`#7/2.` 才是浮点；变浮点后地址可能按 mm 解释。
3. **寄存器单位**：很多参数是 0.001 mm 整数；不 `/1000.` 会放大 1000 倍。
4. **一号多义**：新增报警前先全包搜索该号。
5. **报警占位没换**：只改宏不改报警表，现场只看到“宏程序警报”。
6. **英文/繁中漏改**：三语必须同改。
7. **包内旧文件回退**：安装顺序错会把新文字/新参数覆盖回去。
8. **PLC 编译产物不可读**：文本检索不一定命中，判断逻辑要看源工程。
9. **孪生文件落后**：M 码文件可能比 G 码少逻辑，改主文件后必须回查。
10. **参数方向相反**：同名参数在不同项目可能“0=开/1=关”相反，跨项目照抄必错。
11. **默认值预置**：参数表出厂值填成现场值，会让现场误以为“已设定”。
12. **换行统一转**：整目录转 CRLF 会改动所有文件字节，污染差异。
13. **加密宏**：解码即乱码，不要按文本改写。
14. **同一行多个 G 码**：只有最后一个能读引数，功能宏单独一行。
15. **漏分号**：可能把下一行合并解析，语法合法就不报警。
16. **WAIT 缺失**：写寄存器后立即读，可能预读旧值。
17. **M 码宏占用引数**：可能吃掉后面的轴移动/进给。
18. **T 码不是宏**：T 是否读引数、是否再下 M6，由参数/PLC 决定。
19. **把 `#1~#26` 当临时变量**：会覆盖引数；自由局部区从 `#27` 开始，`#33` 不是引数。
20. **把 G31 触发坐标当任意时刻当前位置**：它只在刚执行对应 G31 后有意义。
21. **把 `@`/R 镜像、`#` 参数镜像、`PARAM()` 当同一个值**：型态/单位/同步方式不同。
22. **往 R 写小数**：R 是 32 位整数；先放大再写，读侧再还原。
23. **间接地址未初始化/越界**：`#[...]`/`@[...]` 先写指针并查边界，否则读到 0、其它变量或直接报错。
24. **英寸长度用 `/25.4`**：本类换算应为 `/2.54`；速度才用 `/25.4`，写反差 10 倍。
25. **速度用 `/2.54`**：应为 `/25.4`。
26. **把参数镜像当当前 LIU**：`@108xxx` 固定按 0.001mm 存，不随 `G70/G71` 改变。
27. **`Pr17=1` 与 `=3` 的方向写反**：`=1` 要 `/10`，`=3` 要 `*10`，`=2` 不变。
28. **只测 `Pr3241=0`**：`=1`、以及 `=1 + G70` 的叠加分支都要单独跑。
29. **`G70/G71` 切换后不恢复**：正常退出恢复、报警/中断退出没恢复，同样会污染后续程序。
30. **`PARAM(n)/1000` 整数截断**：需要小数时写 `/1000.`，否则角度/公差会被截掉。

# 第三部分 备份与交付目录

> 新代固定目录名保留原样；不同版本可能略有差异，以实际备份为准。

## 全备份

```text
<backup>/
├─ Macro/             # 宏程序
├─ Parameter/         # 参数备份
├─ ParameterExt/      # 扩充参数
├─ Ladder/            # PLC 源/编译产物
├─ OCRes/             # 客制画面/资源
├─ AlarmMacro/        # 宏报警文字
├─ AlarmPLC/          # PLC 报警文字
├─ System/            # 系统资料
└─ ...
```

判断要点：

- `Macro/` 里的文件才是宏本体；`Ladder/` 里常见编译产物，文本检索不可靠。
- `ParameterExt/` 里的 pxt/XML 决定扩充参数的号段、上下限与三语文案。
- `AlarmMacro/` 与 `AlarmPLC/` 是两套报警表，不要混改。
- `OCRes/` 里可能含客制画面 XML 与图片资源。

## 交付包

```text
<package>/
├─ Macro/
├─ paramext.pxt
├─ ParamExt_CHS/CHT/COM.xml
├─ AlarmMacro_CHS/CHT/COM.xml
├─ AlarmPLC_CHS/CHT/COM.xml
├─ MST.xml / Backgnd.xml
├─ cnc.lad
└─ package_*.zip
```

判断要点：

- 平铺结构通常是“交付包”，不是全备份；缺 `System/` 等目录属正常。
- `package_*.zip` 里可能嵌有旧版报警/参数；安装顺序错会回退。
- 客制画面与宏/PLC 必须成套，单独拷 `Macro/` 不会更新画面。

## 版本判断

1. 目录名日期；
2. 关键文件修改时间；
3. 文件头版本/日期；
4. 关键文件哈希。

四者互证；只看目录名最容易拿错版本。
