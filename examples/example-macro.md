# 合成示例：一段通用的对刀宏骨架

> 本示例完全虚构，只用于说明结构；变量号、报警号、参数号都是占位，不代表任何厂商实现。

```gcode
%@MACRO
// 用途：单把刀 Z 向对刀，写入刀长表
// 引数：H/T = 刀号；Z = 安全高度；F = 量测进给
// 依赖：#1 刀号、#2 安全高度、#3 进给

#1 := #11;              // H 引数
IF #1 = 0 THEN
    #1 := #20;          // 未给 H 时取 T
END_IF;

IF #1 <= 0 THEN
    ALARM(9001);        // 示例报警：刀号无效
    M99;
END_IF;

#2 := #26;              // Z 安全高度
#3 := #9;               // F 进给

G90 G53 Z#2;            // 回到安全高度
G31 Z-#3 F#3;           // 向下探测

IF #1608 <> 1 THEN
    ALARM(9002);        // 示例报警：未触发
    M99;
END_IF;

#10 := #1443;           // 触发时 Z 机械坐标

// 写刀长表（示例地址，按实际控制器替换）
G10 L10 P#1 R#10;

M99;
```

## 结构说明

1. **引数归一**：H/T 互斥或回退，先判有效刀号。
2. **先回安全高度**：避免从任意位置直接下探。
3. **单段 `G31`**：不与 `G00/G01` 合并，确保能读到 F 与信号。
4. **触发校验**：触发标志未置位必须报警并返回。
5. **写回**：只写该刀对应的刀长表项。
6. **收尾**：`M99` 返回；需要停机时用 `M00`。

## 改造时检查

- 刀号来源是 H 还是 T？两者同给时谁优先？
- 安全高度、进给、公差来自引数还是参数？
- 写回是刀长、磨耗还是坐标系？
- 未触发、刀长无效、越界分别报什么？
- 同功能 M/O 入口是否也要改？
